语音记录物品存放位置，再也不用担心找不到东西了。

智能收纳助手是一款基于 Android 的轻量级收纳管理工具，通过语音录入 + AI 智能解析，让您轻松记录和管理家中物品的位置信息。支持批量识别、多图附件、回收站、深色模式等丰富功能。

✨ 主要功能

  • 🎙️ 语音录入：点击麦克风说话，AI 自动提取物品名称和存放位置
  • 🤖 AI 智能解析：支持单条和批量识别，自动提取物品信息
  • 📦 批量录入：一次性说出多个物品，AI 逐一识别（如“红色的笔在柜子里，蓝色的笔在抽屉里”）
  • 🖼️ 多图附件：每个物品可上传最多 9 张照片辅助记忆
  • 🔍 智能搜索：支持文字搜索、语音搜索、AI 关键词提取，模糊匹配更精准
  • 🗑️ 回收站：误删物品可随时恢复，数据安全有保障
  • 🌙 深色模式：跟随系统或手动切换，深色为微信式深灰层次、更舒适统一
  • 🌐 多语言：简体中文 / 繁體中文 / English，支持跟随系统与手动切换并持久保留
  • 💰 赞助支持：喜欢这个 App？欢迎请作者喝杯咖啡☕

📝 更新内容 v1.1.0

相比 v1.0.1，本次更新如下：

✨ 新增

  • 🌐 界面语言：简体中文 / 繁體中文 / English，可跟随系统或手动选择，切换立即生效、重启保留

🔧 修复

  • AI 解析失败（超时、免费服务不可用、网络/服务端错误、鉴权/额度/限流、空结果等）不再卡死：统一弹「AI 解析未成功」，可「去配置 API」或「稍后」；「稍后」自动用本地规则解析并保留结果继续填写，同一会话不再反复弹窗；「去配置 API」保留已填内容与照片并可返回继续，自动定位到 AI 配置区
  • 移除免费模式界面里“构建时配置 API Key”的开发说明，保留面向用户的免费/自定义切换与使用说明
  • 修复批量识别照片归属错乱（一件多张 / 一张多件 / 部分失败重试均正确保留）
  • 新增全屏照片缩放预览；模型错误分类提示，不再伪装解析完成
